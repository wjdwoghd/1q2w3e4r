# Phase 7.1 보안통제 참고용 매핑

`ControlMappingService.map_finding(finding_id)`는 이미 저장된 Phase 6 Finding의
각 분석 관측을 기준으로 통제를 연결하고 저장한다. `list_for_finding`은 과거
관측까지의 통제, 적용 규칙, 이유 및 관측 사실을 조회한다. 동일 관측·통제·근거의
재실행은 멱등이고 불일치 재실행은 거부한다. 이 결과는 관련 기준의 참고용
연결이며 법적 적용 대상, 인증 또는 규정 준수 여부의 판정이 아니다.

ISMS-P 1.2와 2.10은 안내서에서 확인된 **상위 기준 영역**이다. 세부 통제 번호나
세부 요구사항을 이 영역에서 추측하지 않는다. 금융분야 오픈소스 관리 가이드의
공식 통제 원문과 식별자를 확인하지 못하여 `opensource_guide.json`은 매핑에
사용하지 않는다.

표의 기술적·관리적 구분은 이 플랫폼의 참고용 분류이며 원문이 부여한 등급이 아니다.

## 결정적 매핑 규칙 (`7.1.1`)

| 저장된 관측 사실 | 연결 기준 | 이유 |
| --- | --- | --- |
| 확인된 CVE와 매칭 증거 | 전자금융감독규정 제37조의2 제5항 제1호 | 취약점 제거 또는 상응 조치 관련 조항 |
| 확인된 CVE와 매칭 증거 | ISMS-P 2.10 | 시스템 및 서비스 보안관리 기준 영역 |
| 저장된 위험 분석 결과 | ISMS-P 1.2 | 위험 관리 기준 영역 |
| 관측 당시 `patch_status=overdue` | 전자금융감독규정 제37조의2 제5항 | 취약점 이행계획 수립·시행 관련 조항 |

이 규칙은 Finding을 정식 취약점 분석·평가로 간주하지 않는다. 연결의 적합성은
적용 범위와 실제 원문을 검토하는 담당자가 확인해야 한다.
