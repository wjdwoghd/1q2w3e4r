# standards

컴플라이언스 기준 데이터를 관리한다.

JSON 등 구조화된 형식으로 기준 항목을 저장한다. 기준명, 항목 식별자, 출처, 적용 버전과 확인 시점을 함께 관리할 계획이다. 기준 파일은 사람이 읽을 수 있고 비교 가능한 형태로 유지한다.

목표 파일명은 `financial.json`, `isms_p.json`, `opensource.json`이다. 현재 `opensource_guide.json`을 `opensource.json`으로 변경하는 작업은 아직 수행하지 않았다. 기준 파일은 구현 전의 빈 파일이며, 실제 내용을 검토한 후 채운다. 기준 매핑은 규정 준수의 자동 판정을 의미하지 않는다.
