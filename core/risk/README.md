# risk

금융서비스의 대응 우선순위(Remediation Priority)를 산정하는 규칙 기반 로직을 관리한다.

`calculate_risk_priorities(MatchResult, AssetContext)`는 검증된 매칭 결과의 CVE마다 P1~P4 조치 우선순위와 점수별 근거를 반환한다. CVSS, KEV, 운영 환경, 업무 중요도, 외부 노출, 패치 기한 초과, 신용정보 처리를 반영한다. EOL 정보 연계는 확장 범위로 둔다.

CVSS는 취약점 자체의 기술적 심각도이며 이 엔진의 점수와 구분한다. AI나 ML 모델이 우선순위를 결정하지 않는다. 입력 누락·불일치 정책, 가중치, 경계값의 근거는 [위험 모델 문서](../../docs/risk_model.md)에 있다.

| 파일 | 책임 |
| --- | --- |
| `engine.py` | 취약점 정보와 자산 맥락을 입력으로 전체 계산 수행 |
| `rules.py` | 조건별 점수 규칙 정의 |
| `priority.py` | 계산 결과를 P1 / P2 / P3 / P4로 변환 |

규칙 버전 1.0의 경계는 P1 80점 이상, P2 50점 이상, P3 20점 이상, P4 0점 이상이다. EOL은 확인된 데이터가 없어 미평가로 표시한다.

머신러닝 학습·추론 로직과 학습 모델 저장 디렉터리는 두지 않는다.
