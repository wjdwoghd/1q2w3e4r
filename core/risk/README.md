# risk

금융서비스의 대응 우선순위(Remediation Priority)를 산정하는 규칙 기반 로직을 관리한다.

CVSS, KEV 여부, 운영 환경, 자산 중요도, 외부 노출 여부, 패치 지연 기간 등을 조합해 P1~P4를 계산할 계획이다. EOL 정보 연계는 확장 범위로 둔다. 가중치와 등급 경계는 구현 단계에서 확정한다.

CVSS는 취약점 자체의 기술적 심각도이며 이 엔진의 계산 결과와 구분한다. AI나 ML 모델이 우선순위를 결정하지 않으며, 적용 규칙과 입력값으로 계산 근거를 설명할 수 있어야 한다. 현재 파일은 구현 전의 빈 파일이다.
